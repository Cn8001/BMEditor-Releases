# BMEditor 0.1.2

- **New:** Work on another machine. Open a folder in WSL, on an SSH host (a
  server, a VM or another Windows computer) or in a Docker container, all
  from the same window. There is nothing to install there: BMEditor sets
  itself up on the first connection. Passwords, key passphrases and codes
  are asked right in the editor, and a dropped connection can be brought
  back without losing unsaved changes. See
  [Working on another machine](https://github.com/Cn8001/BMEditor-Releases/blob/master/docs/remote.md).
