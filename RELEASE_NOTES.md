# BMEditor 0.1.7

A hotfix release on top of 0.1.6.

## New

- The side panel runs GitHub Copilot CLI as well as Claude Code. Pick one
  from the panel's title or from the Assistant page in Settings; a running
  one is replaced when you switch. Copilot needs the `copilot` command
  (`npm install -g @github/copilot`) and a Copilot plan.
- Letting the assistant use the debugger and Docker works for Copilot CLI
  too.
- Extensions can open one of their views in a window of its own, which you
  can move anywhere.
- An extension setting that turns a whole part on or off shows in Settings
  as an On/Off switch.
